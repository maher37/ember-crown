# Mockups

These are the source files of the design canvas made in Claude chat. They use a design-canvas runtime and **won't run on their own**. Read them for:
- **Layout and sizes:** each screen is 1280×720.
- **Palette and fonts:** see CLAUDE.md, "Look and feel".
- **Copy:** labels, dialogue text and jokes.
- **Behavior:** the `renderVals()` logic in each file shows how the screen should react, for example the level-up hover previews, the camp rest rules, and travel rolls.

| File | Screen |
|---|---|
| Main.dc.html | Title, difficulty, dice and save settings |
| CharacterCreator.dc.html | Party creation, Corin origin, portrait builder |
| Portrait.dc.html | Layered SVG portrait component |
| Exploration.dc.html | Tavern exploration, journal, party bar |
| Combat.dc.html | Grid combat, initiative, action economy, dice log |
| Dialogue.dc.html | Dialogue with party-best skill checks |
| WorldMap.dc.html | Original travel map, calendar, road-encounter rolls |
| LevelUp.dc.html | Level-up with ability hover previews |
| Camp.dc.html | Animated camp (wilderness, inn, cave), Wix, letters |
