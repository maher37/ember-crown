# Decisions (the D-table)

The current list of design decisions, in number order. **This is the file to read for "what did we decide?"** Each row records the decision, a short reason and its date or owner note.

- ✅ means decided. ❓ means open: ask the owner before building anything that depends on it.
- When a decision changes, edit its row here in the same PR as the code change.
- The original Nov 15 plan these rows came from is archived at `docs/archive/RPG_Game_Plan_Nov15.md`. It's history only; don't build from it.

| # | Decision | Decided | Notes |
|---|---|---|---|
| D1 | **Rules version**: 2014 (SRD 5.1) or 2024 (SRD 5.2) | ✅ **DECIDED: SRD 5.1 (2014).** BG3 is built mostly on 2014 rules, so it will feel familiar. Both SRDs are free to use under CC-BY-4.0. | Spells, class features and monster stat blocks differ between versions. Mixing them causes bugs and arguments. |

| D5 | **Platform / tech** | ✅ **As built: browser game, Vite + React + TypeScript, rendered with HTML/CSS and inline SVG** (no canvas library yet). Full stack in CLAUDE.md. | The original plan suggested Phaser or PixiJS; SVG proved enough. |

## Balance targets (used by `npm run balance`)
These are the targets the balance simulator reports against ([inferred] from the original plan; tune with the owner):
- Main-path fights won 85–97% of the time on Medium at the expected level.
- Fights designed as Hard: 75–95%.
- Elites: 40–85% (Deadly by design).
- Travel encounters: 90% or more.
- At expected level +1 (the side-quest bonus), main fights should be won nearly always.
